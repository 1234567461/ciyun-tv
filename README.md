# 慈云影视 · Ciyun TV

> 免费 · 高清 · 无广告 —— 一个基于**官方公开接口**的开源影视聚合平台

聚合央视网（tv.cctv.com）等官方公开资源，提供**点播 + 直播 + 搜索**完整能力，
并内置账号体系、评论、家庭共享、同源聊天室、弹幕与可选会员付费模块。

## ✨ 功能特性

### 内容
- **点播**：**276 个央视官方栏目**（实测可用），HLS 自适应播放
- **直播**：16 个央视频道，EPG 节目单实时同步
- **搜索**：站内全量聚合搜索
- **多源**：统一源适配层 —— 央视官方 + 8 个公开苹果 CMS 采集站 + M3U / 直链 / 自定义 JSON
- **多线路**：同一视频多条播放线路，支持失败自动切换与自动优选

### 社区
- **账号体系**：注册 / 登录 / 改密 / 资料 / 头像，PBKDF2-SHA512 加盐哈希
- **评论**：两级嵌套回复、点赞、敏感词过滤、频率限制、先审后发
- **同源聊天室**：看同一部片 / 同一个频道的用户实时聊天（SSE 推送）
- **弹幕**：本片弹幕 + 全站弹幕，7 种颜色、3 种位置，轨道防重叠
- **短视频（小型 B 站）**：竖屏刷视频流 + 网格广场 + 详情页 + 拖拽上传
  - 刷视频流支持滚轮 / 键盘 / 触摸滑动切换，相邻视频预加载
  - 上传带七层校验（类型 / 大小 / 魔数 / 分辨率 / 时长）、每用户 20 次/小时限流
  - 播放量自动计数、点赞、评论（复用通用评论组件）、作者可删自己的视频
- **社交**：加好友 / 好友申请 / 私信，顶栏带未读红点

### 公告中心
- **顶部滚动公告栏**：常驻页头下方跑马灯播报，内容溢出才滚动，可一键收起
- **公告弹窗**：首次进入或内容变更时弹一次，支持「不再提示」
- **多条公告管理**：后台可维护多条，每条独立控制
  启用 / 顶部滚动 / 弹窗 / 级别（普通·成功·提醒·重要）/ 生效时间段
- **监控联动**：可对接配套监控服务，在监控端改一处即全站生效（未部署则用本地公告兜底）

### 家庭共享（对标 Emby / Jellyfin / Plex）
- **1 位户主 + 最多 5 位成员**绑定，会员权益共享
- **多角色权限矩阵**：户主 / 家庭管理员 / 成员 / 儿童 / 访客，逐项控制观看、超清、下载、评论、邀请、管理、共享额度
- **并发流限制**：每成员最大同时在线路数，超额可选「顶掉最早会话」或「直接拒绝」（对标 Jellyfin `MaxActiveVideoStreams`）
- **设备数限制**：每成员最大绑定设备数，设备指纹自动登记与解绑（对标 Emby 设备上限）
- **家庭额度池**：户主设置共享额度池，成员额度耗尽时自动扣池（对标 Plex Home 权益下放）
- **邀请码多态**：可指定角色、可用次数、有效期；支持户主二次审核（`autoApprove`）
- **内容分级**：儿童等级上限（G/PG/PG-13/R）+ 禁用超清下载 + 禁言（对标 Jellyfin Parental Rating）
- 可配置「需会员才能创建」、成员主动退出、邀请码默认策略

### 会员付费（可选，默认关闭）
- **三层开关**：`monetize.enabled`（付费总开关）→ `monetize.quotaEnabled`（额度二级开关）→ 具体规则，总开关关闭时额度永不生效
- 套餐管理、下单、支付回调、VIP 发放与到期
- **额度系统**：每日免费额度、观看次数额度、通用点数，超额硬性拦截
- **兑换码四态**：会员天数 / 余额 / 观看次数 / 通用点数
- 核心影视观看**永久免费**，付费仅提供增值权益

#### 支付渠道（6 种，可自由增删改启停排序）

| 类型 | 说明 | 需要配置 |
|------|------|----------|
| 🧪 `mock` | 模拟支付，一键成功 | 无需配置（默认启用，用于本地演示） |
| 🌈 `epay` | 易支付 / 彩虹易支付 | 网关、商户号 PID、密钥 Key、签名算法 |
| 🅰️ `alipay` | 支付宝官方（电脑网站支付 / 当面付） | AppID、应用私钥、支付宝公钥 |
| 💚 `wxpay` | 微信支付 V3 Native 扫码 | AppID、商户号、证书序列号、APIv3 密钥、商户私钥 |
| 🏦 `manual` | 人工收款：展示收款码，用户提交凭证、管理员确认 | 收款码、收款人、账号、说明 |
| 🔧 `custom` | 自定义网关，回调仍走本站 | 下单跳转地址、签名密钥 |

- **增删改启停**：后台「会员付费 → 支付渠道」可视化增删、一键启停、拖拽排序（数值）、逐字段配置
- **配置自检**：保存时自动校验必填项 + RSA/微信私钥可解析性，未配置完整的渠道前台不展示
- **多支付方式**：同一渠道可挂载支付宝 / 微信 / QQ 钱包，前端按渠道展示下拉选择
- **真实签名**：支付宝 RSA2（`RSA-SHA256`）、微信支付 V3（`SHA256-RSA2048`）、易支付 MD5/SHA256
- **回调验签**：签名比对 + 金额一致性校验 + 幂等发放（同一订单重复回调不重复发权益）
- **订单状态机**：`pending` → `claiming`（人工凭证待审）→ `paid` / `rejected` / `cancelled` / `refunded`

## 🚀 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 生成栏目库（已内置 columns.json，此步可选）
npm run seed          # 使用内置央视栏目清单
npm run sync:cctv     # 或从央视官方接口实时同步（需联网）

# 3. 启动服务（默认端口 8811）
npm start
```

访问：

| 入口 | 地址 | 默认账号 |
|------|------|----------|
| 前台 | http://localhost:8811/ | — |
| 后台 | http://localhost:8811/admin/ | `admin` / `admin888` |

> ⚠️ **部署到公网前请务必修改后台密码**：后台「站点设置 → 管理员」处可修改。

## 🛡️ 安全说明

| 项目 | 实现 |
|------|------|
| 密码存储 | PBKDF2-SHA512 · 16 字节盐 · 10 万次迭代 |
| 时序攻击防护 | `crypto.timingSafeEqual` 常量时间比较 |
| 会话 | 随机 24 字节 token，HttpOnly Cookie |
| 多设备 | 单账号最多保留 5 个登录 token |
| 评论防护 | 敏感词过滤 + 外链拦截 + 频率限制 + 先审后发 |
